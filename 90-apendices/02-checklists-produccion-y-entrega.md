# Checklists de producción y entrega

## Contrato

- [ ] URIs, métodos y status conservan semántica.
- [ ] DTO y errores están documentados.
- [ ] Compatibilidad y versionado fueron revisados.

## Datos

- [ ] Migraciones son reproducibles y revisadas.
- [ ] Dinero, moneda, tiempo e idempotencia son explícitos.
- [ ] Consultas críticas poseen evidencia de plan.

## Operación

- [ ] Health, métricas, logs y correlation ID son seguros.
- [ ] Timeouts y presupuesto de retries están definidos.
- [ ] Rollback y limitaciones conocidas están documentados.
