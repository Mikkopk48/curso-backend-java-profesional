# Plan para acompañar la diplomatura

Antes de cada clase utiliza el archivo 94 correspondiente. Durante la clase registra versiones, diferencias y preguntas. Después completa teoría y práctica mínima en 48 horas, y recupera el concepto una semana más tarde.

Si la clase ya utiliza Spring Boot y partes desde cero, realiza primero la ruta esencial de la unidad 5. Puedes escuchar contenido posterior en paralelo, pero no construyas sobre controller/service/repository hasta poder seguir una petición y diagnosticar el arranque.

Si la clase agrupa unidades, prioriza el contrato oficial y pospone ampliaciones. Si cambia el orden, respeta dependencias: Spring Boot básico antes de la API avanzada; HTTP antes de contratos distribuidos; unidad antes de integración; transacciones antes de separar datos; seguridad desde el diseño y en profundidad en la unidad 25.

Cada tres unidades revisa una evidencia anterior y mejora explicación, test o decisión.
