# Cómo pedir ayuda y depurar

## Informe útil

Incluye contexto, objetivo, versión, pasos, resultado esperado, resultado real, mensaje completo y ejemplo mínimo. Oculta tokens, contraseñas, datos personales y URLs internas.

## Orden de diagnóstico

1. Reproduce de forma determinista.
2. Lee desde la primera causa relevante.
3. Comprueba entrada y configuración efectiva.
4. Reduce capas hasta localizar frontera.
5. Formula hipótesis falsable.
6. Añade una observación segura.
7. Corrige causa y añade test de regresión.

Pedir una pista por ID conserva aprendizaje. Pedir código completo antes de intentar elimina la parte que desarrolla criterio.
