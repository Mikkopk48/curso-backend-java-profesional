# Método de práctica deliberada

## Bucle

Predice, implementa poco, ejecuta, observa, explica y refactoriza. Un error es evidencia: conserva el mensaje completo, reduce el caso y cambia una sola variable.

## Evidencia mínima

- commit atómico;
- test o comando reproducible;
- resultado esperado y observado;
- explicación del riesgo;
- límite conocido.

La distribución global es 30 % consolidación, 40 % intermedia, 20 % avanzada y 10 % opcional. No uses el nivel para juzgar importancia: los fundamentos sostienen todas las capas posteriores.
