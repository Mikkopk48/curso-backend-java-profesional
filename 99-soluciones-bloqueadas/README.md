# Soluciones bloqueadas

Este directorio no contiene respuestas, claves ni implementaciones. Las soluciones se crearán únicamente cuando Mikko solicite de forma inequívoca un ID concreto, por ejemplo: MOSTRAR SOLUCIÓN U09-E04.

Antes de mostrar una solución completa se revisará el intento, se señalará el primer error conceptual importante y se ofrecerá una pista y una segunda oportunidad.
